In Mali, if post-coup violence were jihadist resurgence, non-state killings would be rising. Instead, they are holding flat. Stanton's strategic-violence framework fits this asymmetry: hierarchical regime forces respond to audience-cost calculations differently from loose insurgent groupings [Stanton 2016]. Mali fits Kalyvas's indiscriminate-violence pattern in zones a regime cannot fully control [Kalyvas 2006]. Hultman documents this for rebels [Hultman 2007]. Marten describes Wagner's African expansion [Marten 2023].
