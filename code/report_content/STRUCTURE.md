# Report Structure & Authorship Map

> **Purpose:** Defines the prose-block file structure for `docs/index.html`. Each block is owned by exactly one specialist agent. The main session does not author content; `Z_generate_report.py` (data-scientist) reads these files and assembles the HTML.

> **Target word count:** **1,300–1,700 words** of analytical prose (excluding code, references, captions). The structure below allocates 1,500 words; copy-edit pass may trim.

> **Figures available** (in `docs/figs/`): `fig_01_monthly_events.html`, `fig_02_civilian_fatalities_by_role.html`, `fig_03_pre_post_wagner_ratio.html`, `fig_04_vdem_regime.html`, `fig_05_mali_geographic.html`.

> **Source of truth for numbers:** `data/final_stats.json` (137 keys, generated by `03_analysis.ipynb`). Do NOT compute new statistics; cite values from this JSON. Numbers in prose must be parameterised so `Z_generate_report.py` substitutes them at render time (see token format below).

> **Number-token format:** prose files use `{key}` tokens for any numeric value, where `key` matches a JSON key. Example: `"Civilian fatalities rose from {mali_civ_pre_rate}/month before Wagner's deployment to {mali_civ_post_rate}/month afterwards (×{mali_civ_ratio} increase, 95% CI {mali_civ_ci_low}–{mali_civ_ci_high})."` This guarantees that no number in the report ever drifts from the analysis pipeline.

> **Citation-token format:** prose uses `[Author Year]` tokens. The renderer maps these to the verified bibliography in `plan/CITATION_VERIFICATION_LOG.md` (Round 1 + Round 2). Only the 22 ✅ VERIFIED citations may be cited.

## Tone & voice rules (binding for both agents)

1. **Active analytical voice.** "We find…", "The data show…", "This pattern is consistent with…". Avoid passive padding ("It can be observed that…").
2. **Hedged where uncertainty is real.** When the post-Russian window is short (BF, Niger), say so explicitly. Do not make causal claims from the regression alone — say "consistent with" rather than "caused by".
3. **No filler.** Every sentence either advances a claim, supplies evidence, or names a counter-argument. No "It is interesting to note that…".
4. **No first-person plural in casual mode.** "We" = the analyst (Si Woo Kim); avoid royal-we drift.
5. **Signal authority by precision.** If a number is being cited, give the value; if a citation is being made, name the author and year inline.
6. **Length discipline.** Each block must hit its word target ±10%. Over-budget blocks will be cut by the english-expert pass.
